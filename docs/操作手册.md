# boook-web 用户操作手册

> 本手册面向**使用这套系统的人**（读者与管理员），不讲代码与部署原理。
> 所有操作步骤均按 v1.0 实际界面核对编写；界面文案以系统实际显示为准。
> 开发与部署的详细配置请分别看 `README.md` 与 `部署指南.md`。

---

## 1. 系统能做什么

boook-web 是一套图书馆藏书管理系统：读者可以在线查书、借书、还书、预约被借走的书；管理员可以建档案（含扫码识别 ISBN）、管理馆藏、查看全馆统计；系统还会在书到期前主动提醒、在预约的书归还时通知你。所有数据都是真实馆藏数据，AI 助手的回答也严格基于馆内实际藏书。

功能清单：

- **注册 / 登录**（两种角色：读者、管理员）
- **馆藏列表**：搜索、分类筛选、表格⇄卡片视图、分页、批量借阅 / 批量删除（管理员）/ 导出 CSV、键盘快捷键
- **图书详情**：借阅 / 归还 / 预约、借阅历史、相关推荐、管理员删除（可撤销）
- **扫码建档**（管理员）：摄像头扫 ISBN 条码或手输，自动回填书名作者等档案信息
- **借阅记录**：在借 / 已还 / 逾期筛选，应还日期一目了然
- **看板**：近 30 天借出趋势、馆藏分类占比、借阅次数排行
- **AI 馆藏助手**：用大白话问馆藏（「馆里有哪些科幻小说？」）
- **站内通知**：预约到货、到期前 3 天提醒
- **PWA**：可安装到桌面 / 手机主屏，断网也能看之前加载过的书单
- **深色 / 亮色 / 跟随系统**三种主题

## 2. 把系统跑起来

### 2.1 Docker 一键部署（推荐）

前提：机器上装有 Docker。在项目目录执行：

1. **准备数据库**（首次）：创建 `fastapi-net` 网络并启动一个 MySQL 容器，命令见《部署指南.md》第 1 节。
2. **设置三个必填环境变量**（PowerShell 示例，值换成你自己的）：

   | 变量 | 作用 |
   |---|---|
   | `MYSQL_ROOT_PASSWORD` | 数据库密码（MySQL 和应用共用） |
   | `JWT_SECRET` | 登录凭证的加密密钥，随意但至少 32 个字符 |
   | `ADMIN_INIT_PASSWORD` | 第一次启动时自动创建的管理员 admin 的密码 |
   | `DEEPSEEK_API_KEY`（可选） | 配了才能用 AI 助手 |

3. **启动**：`docker compose up -d --build`
4. **确认就绪**：浏览器打开 `http://localhost:8080`，能看到深色的登录页即成功；也可用 `docker inspect --format '{{.State.Health.Status}}' boook-web` 看到 `healthy`。

> 关于 **ADMIN_INIT_PASSWORD**：系统数据库里没有任何管理员账号时，应用启动那一刻会用这个变量的值自动创建用户名 `admin` 的管理员。之后该变量就不再起作用（已有 admin 就不会重复创建）。忘记密码请联系维护者重置数据库或换一个新库。

### 2.2 本地开发模式

供改代码的人使用，见 `README.md`「本地开发启动」一节（后端 `./mvnw spring-boot:run` + 前端 `npm run dev`）。

### 2.3 访问地址

- 部署版：`http://localhost:8080`（前端界面和后台接口同一个地址）
- 本地开发：前端 `http://localhost:5173`（后台在 8080）

### 2.4 常用运维操作

| 想做什么 | 命令 |
|---|---|
| 停止 | `docker compose stop` |
| 再次启动 | `docker compose start` 或 `docker compose up -d` |
| 改了代码重新打包启动 | `docker compose up -d --build` |
| 看运行日志 | `docker logs -f boook-web`（按 Ctrl+C 退出查看，不影响系统） |
| 看健康状态 | `docker inspect --format '{{.State.Health.Status}}' boook-web` |

## 3. 注册与登录

### 3.1 注册（即成为读者）

**在哪**：登录页底部「去注册」→ **做什么**：填写用户名、密码、确认密码，点「注册」→ **应该看到**：提示「注册成功，请登录」，页面自动返回登录表单且用户名已预填，输入密码登录即可。

注册成功的账号角色固定为**读者（reader）**；管理员由第 2.1 节的机制自动创建，不开放注册。若用户名已被占用会提示「用户名已存在」，换一个即可。

### 3.2 两种角色权限一览

| 功能 | 读者 | 管理员 |
|---|---|---|
| 搜索、看馆藏、看详情、看看板 | ✅ | ✅ |
| 借书 / 还书 / 预约 | ✅ | ✅ |
| 查看自己的借阅记录 | ✅ | ✅（还能看到所有人的记录） |
| 批量借阅、导出 CSV | ✅ | ✅ |
| 扫码建档、添加新书 | ❌ | ✅ |
| 删除图书（单个 / 批量） | ❌ | ✅ |
| ISBN 在线查询回填 | ❌（接口仅管理员） | ✅ |
| 查看所有用户的借阅记录 | ❌ | ✅ |

### 3.3 登录有效期

登录后获得的通行证（专业名：token，可以理解为一张 24 小时的临时门禁卡）**24 小时过期**。过期后系统会弹提示并自动把你带回登录页，重新登录即可，不会丢失任何数据。

### 3.4 登录页的 3D 背景

登录页背后是一层 3D 粒子星空（静态背景，缓慢自转；桌面端约 800 个粒子，手机端自动减少）——这是装饰效果，不影响表单操作。如果系统（或浏览器）开启了「减少动态效果」，星空会自动换成静态背景，属正常表现。

## 4. 馆藏列表页（首页）

登录后首先看到的就是馆藏列表页。顶部横向统计条显示：**馆藏总量、在馆数量、在借数量、分类数**（全库真实统计，与当前页显示多少本书无关）。

### 4.1 搜索

**在哪**：统计条下方的搜索框（提示文字「搜索书名 / 作者」）→ **做什么**：输入书名或作者的关键词，不用按按钮、输入即查 → **应该看到**：表格实时只显示匹配的书；搜索由服务器完成，翻页时搜索条件依然保持。

### 4.2 分类筛选

搜索框旁边一排分类按钮（「全部」「未分类」「文学」…，按钮由馆内实际分类自动生成）→ 点某个分类 → 列表只显示该分类的书；可与搜索关键词叠加使用。点「全部」恢复。

### 4.3 表格 ⇄ 卡片视图

- **表格视图**：一行一本书，信息密、适合逐条浏览，行的最后有「借阅」按钮。
- **卡片视图**：书名做成一张张卡片，适合浏览封面式的概览。
- 点右侧的「表格视图」/「卡片视图」按钮随时切换。

### 4.4 分页

列表底部显示「共 N 条 · 第 x / y 页」，用「上一页 / 下一页」翻页。翻页时搜索词和分类筛选都会保留。

### 4.5 批量操作

**在哪**：表格每行最左侧有勾选框，表头有「全选本页」→ **做什么**：勾选若干本书 → **应该看到**：表格上方出现操作条「已选 N 本」：

- **批量借阅**：把选中的在馆书一次全部借走（已在借的书会提示失败原因）。
- **导出 CSV**：把选中的书导出为表格文件，可用 Excel 打开。
- **批量删除**（仅管理员可见）：删除选中的书；删除后底部弹提示，5 秒内可点「撤销」恢复。
- **取消选择**：清空勾选。

### 4.6 键盘快捷键

| 按键 | 效果 |
|---|---|
| `/`（斜杠） | 光标直接跳到搜索框 |
| 方向键 ↑ ↓ | 在表格行之间移动选中行 |
| 回车 | 对选中行执行借阅 |
| Esc | 关闭当前弹窗 |

### 4.7 手机窄屏

屏幕宽度小于约 768px 时，表格自动变成卡片布局，按钮加大到适合手指点击（≥44px），横向不会出现滚动条。

## 5. 图书详情页

**入口**：列表中点书名链接。

### 5.1 字段含义

| 字段 | 含义 |
|---|---|
| 书名 / 作者 | 基本信息 |
| 分类 | 如「科幻」「文学」；早期入库的旧书显示「未分类」 |
| 出版社 / ISBN | 出版信息；ISBN 是国际书号 |
| 在馆复本 | 馆里登记了几册（仅作展示，借阅按「在馆 / 在借」整体状态算） |
| 简介 | 建档时录入的介绍文字，可能为空 |

### 5.2 借阅与归还

- **在馆的书**：详情页显示绿色「在馆」标签和**「借阅」**按钮 → 点「借阅」→ 标签翻转为「在借」，按钮变成**「归还」**，底部弹出「借阅成功」提示（同时告知应还日期）。
- **你借的书**：点**「归还」** → 标签翻回「在馆」，借阅历史里该条记录补上归还时间。
- 应还日期 = 借出时刻 + 30 天（由服务器计算，与你的电脑时间无关）。

### 5.3 预约（书被别人借走时）

- 只有**在借**的书才显示「预约 →」入口 → 点它 → 提示预约成功，你的名字进入该书的等候队列。
- **重复预约**同一本书会被拒绝（提示「您已预约本书，请勿重复预约」）。
- **到货通知**：书一归还，队列里最先预约的人会收到站内通知「您预约的《书名》已归还，当前可借」，收到后尽快去借（谁先点借归谁）。
- 在馆的书不需要也不能预约（提示「图书在馆，可直接借阅，无需预约」）。

### 5.4 相关推荐是怎么来的

详情页下方的「相关推荐」按两种方式生成：

1. **借过这本书的人还借过什么**（按重合次数排序，最多 6 本）——有共同借阅记录时用这个；
2. 若还没有人借过（比如刚入库的新书），退而求其次推荐**同分类里最近入库的其他书**。

### 5.5 借阅历史

详情页下方表格列出这本书最近 5 条借还记录（借阅人、借出时间、应还日期、归还时间、状态），最新的在最上面。

### 5.6 管理员：删除与撤销

**在哪**：详情页（管理员登录时）→ **做什么**：点**「删除此书（撤销窗口 5 秒）」**→ **应该看到**：书从列表消失，底部弹出提示条，**5 秒内点「撤销」**可原样恢复；超过 5 秒即真正删除。删除操作不会抹掉借阅历史记录（记录只改状态、永不物理删除）。

## 6. 扫码建档（管理员）

**在哪**：列表页右上「扫码建档」按钮（仅管理员能看到）→ **做什么**：

1. 弹窗会先尝试使用摄像头扫描 ISBN 条码（需要浏览器支持条码识别能力、且授权了摄像头权限）；
2. 浏览器不支持摄像头识别时，弹窗自动变成**手输模式**（提示「当前浏览器不支持 BarcodeDetector，已切换为 ISBN 手输」），手动输入书背面的 ISBN 数字点「查询」；
3. 查询命中 → 自动回填书名 / 作者 / 出版社 / 封面 / 简介，确认或修正后提交建档；
4. **查询失败**（常见于网络到不了境外书源）→ 提示「未查到该书目，请手动录入」，此时请改用人工方式录入书名作者等信息建档，不会丢失已填内容。

## 7. 借阅记录页

**在哪**：顶栏「借阅记录」。

- 四个筛选按钮：**全部 / 在借 / 逾期 / 已还**。「逾期」不是单独存的状态，而是系统实时算出来的（在借且已过应还日期）。
- 表格列：书名、作者、借出时间、**应还日期**（= 借出 + 30 天）、归还时间、状态。
- **读者**只能看到自己的记录；**管理员**打开该页直接看到**所有用户**的借阅记录。
- 读者本人的全部借还流水也能在「个人中心」（顶栏头像进入）看到汇总：我的在借、我的逾期、未读通知、借阅历史。

## 8. 看板页

**在哪**：顶栏「看板」。三组图全部来自全馆真实数据（与列表页当前分到第几页无关）：

| 图 | 含义 |
|---|---|
| 趋势折线图 | 近 30 天每天借出了多少本书（只画有借出的日期） |
| 分类占比饼图 | 馆藏按分类的数量分布 |
| 排行榜 | 被借次数最多的前 10 本书（含已归还的借阅行为） |

## 9. AI 馆藏助手

**在哪**：任何页面右下角的悬浮按钮（闪光图标）→ 打开「AI 馆藏助手」侧栏。

- 面板预置三个示例问题可直接点击：「馆里有哪些科幻小说」「《三体》能借吗」「帮我找找马尔克斯的书」；也可在输入框用大白话提问。
- **能问什么**：馆里有哪些某类书、某本书在不在馆、按作者找书。
- **回答纪律**：AI 只根据馆内真实藏书回答，查不到的书会明确告诉你「馆内没有」，不会编造书名。
- 回答中的《书名》可以点击，直接跳到该书详情页。
- 如果部署时没有配置 AI 的密钥（`DEEPSEEK_API_KEY`），提问会收到「**AI 服务未配置**」的明确提示——这不是故障，配置密钥后即可使用（见附录）。

## 10. 站内通知

**在哪**：顶栏铃铛图标（有未读时显示红色数字角标）→ 点开「站内通知」弹窗（排序规则：未读优先，最新在前）。

你会收到两类通知：

1. **预约到货**：你预约的书被归还时（详见 5.3 节）；
2. **到期提醒**：你借的书**到期前 3 天**，系统每天早上 9 点自动扫描一次并发出提醒（同一本书同一人每天至多提醒一次，不会轰炸）。

## 11. PWA（安装到桌面 / 手机）

boook-web 是一个 PWA（可以理解为「能装进设备、像 App 一样打开的网页」）：

- **电脑安装**：用 Chrome / Edge 打开系统后，地址栏右侧会出现「安装」图标 → 点安装 → 桌面出现独立窗口的 boook-web。
- **手机安装**：浏览器菜单 →「添加到主屏幕」。
- **断网可用**：安装后断网时，之前加载过的**书单**仍能打开浏览（数据来自本地缓存）；重新联网后数据自动同步为最新。
- 注意：断网时只能「看」，借还等操作需要联网。

## 12. 主题与动效

- **主题三态**：顶栏太阳 / 月亮图标按钮循环切换 **深色（默认）→ 亮色 → 跟随系统**。按钮文字即时显示当前状态（如「主题：light」）。「跟随系统」会按你设备系统的深浅色设置自动变化。
- **减少动态效果**：若你的系统开启了「减少动态效果」（Windows：设置 → 辅助功能 → 视觉效果；macOS：辅助功能 → 显示），页面的入场动画、登录页星空等会自动关闭或退化为静态，无需在系统内做任何设置。

## 13. 常见问题 FAQ

**Q1：借书时提示「该书刚被借走」？**
现象：点借阅（或批量借阅）时弹出该提示（错误码 40901）。
原因：就在同一瞬间，别人先你一步把这本书借走了（两人抢同一本，系统保证只有一人成功）。
怎么办：刷新列表确认状态，可对这本书发起**预约**，归还时会通知你。

**Q2：提示登录失效 / 「token 已过期，请重新登录」？**
现象：操作时弹出提示并被带回登录页（错误码 401）。
原因：登录凭证 24 小时有效期到了（见 3.3 节）。
怎么办：重新登录即可，不影响任何数据。

**Q3：提示「无权限：该操作需要 admin」？**
现象：点某些按钮被拒绝（错误码 403）。
原因：该操作仅管理员可用（见 3.2 权限表），读者账号尝试执行管理操作。
怎么办：找管理员处理；若你本来就是管理员却收到此提示，说明当前登录的不是管理员账号——退出后用 admin 登录。

**Q4：扫码建档提示「外部书源暂时不可用，请稍后重试或手动录入」？**
现象：输入 ISBN 查询后没有回填任何信息。
原因：ISBN 信息来自境外公开书源（OpenLibrary、Google Books），当前网络到不了这两个站点。
怎么办：稍后重试，或直接手动录入书名 / 作者等信息完成建档（错误提示本身就是引导手动录入，不报错、不丢数据）。

**Q5：AI 助手提示「AI 服务未配置」？**
原因：部署时没有设置 `DEEPSEEK_API_KEY` 环境变量。
怎么办：由维护者按《部署指南.md》补上密钥并重启容器（`docker compose up -d`）。

**Q6：为什么我部署出来的数据和另一台机器不一样？**
原因：每套部署连的是各自的数据库，书和账号都存在各自库里，互不相通（比如开发机连本机 MySQL，Docker 部署连容器里的 MySQL，是两套数据）。
怎么办：属正常现象。要在某套环境里演示特定数据，就在那套环境里录入 / 导入。

## 14. 附录：环境变量速查表

> 只列名字与一句话用途；取值方法与默认值详见 `README.md` 第一节。

| 变量 | 用途 |
|---|---|
| `SPRING_DATASOURCE_URL` / `USERNAME` / `PASSWORD` | 数据库连接三件套 |
| `JWT_SECRET` | 登录凭证加密密钥（≥32 字符） |
| `ADMIN_INIT_PASSWORD` | 首次启动自动创建 admin 的密码 |
| `BORROW_DAYS` | 借期天数（默认 30） |
| `ISBN_PROXY_TIMEOUT` | ISBN 查询超时毫秒数（默认 5000） |
